## Чтобы получить HTTPS ссылку (работает отовсюду):

### Вариант 1: Установи ngrok
1. Скачай: https://ngrok.com/download
2. Распакуй в папку проекта
3. Запусти:
   ```bash
   ngrok http 5003
   ```
4. Получишь ссылку типа: `https://abc123.ngrok.io`

### Вариант 2: Cloudflare Tunnel (бесплатно)
```bash
cloudflared tunnel --url http://localhost:5003
```

### Вариант 3: Без HTTPS (только локальная сеть)
На телефоне открой: `http://<IP_ПК>:5003`
