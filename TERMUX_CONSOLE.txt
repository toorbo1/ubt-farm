📱 ИНСТРУКЦИЯ ДЛЯ TELENA - Что писать в консоли Termux на телефоне
==================================================================

ШАГ 1: Установи Termux
- Открой F-Droid.org на телефоне
- Найди "Termux" и установи
(НЕ из Google Play!)

ШАГ 2: Открой Termux и скопируй ВСЕ команды ниже целиком:

------------------------------------------------------------------
# Обновить систему
pkg update && pkg upgrade -y

# Установить нужные пакеты
pkg install python git ffmpeg openssh wget curl nodejs -y

# Создать папку для проекта
mkdir -p ~/ubt-farm
cd ~/ubt-farm

# Установить Flask и зависимости
pip install flask boto3 pydantic-settings httpx pillow

# Скачать проект (если есть GitHub)
# ИЛИ скопировать файлы с ПК через adb/scp

# Запустить сервер (порт 5001)
python -m venv venv
source venv/bin/activate
python web_app/app.py --port 5001
------------------------------------------------------------------

ШАГ 3: После запуска открой на телефоне:
http://localhost:5001

ШАГ 4: Чтобы дать доступ с ПК к телефону:
На ПК выполни: adb reverse tcp:5001 tcp:5001
