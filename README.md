# UBT Traffic Farm 🚀

Полностью автоматизированная система генерации вирусных видео для TikTok с использованием цепочки из нескольких ИИ. Каждый этап создания контента — от написания сценария до финального монтажа — выполняется искусственным интеллектом.

## 🤖 Архитектура: какие ИИ за что отвечают

Система построена как конвейер из трёх основных ИИ-компонентов:

### **AI #1 — Текст и сценарий (LLM)**
*Отвечает за креативную часть: идеи, сценарии, озвучку*

- **Основные модели**: DeepSeek Chat, Claude Sonnet, Gemini
- **Что делает**:
  - Генерирует цепляющие тексты для видео (30-50 слов)
  - Создаёт детальные сценарии из 3-5 сцен с разбивкой по кадрам
  - Пишет narration (озвучку) от лица главного героя — чёрного пиксельного котика
  - Формирует промпты для генерации изображений на английском языке
  - Выделяет ключевые слова для визуальной подсветки
  - Генерирует хештеги для продвижения

- **Режимы работы**:
  - Онлайн через API (DeepSeek, OpenRouter)
  - Офлайн с комбинаторными промптами (без повторов внутри одного видео)

### **AI #2 — Генерация изображений**
*Превращает текстовые описания сцен в визуальный контент*

- **Доступные сервисы** (в порядке приоритета):
  1. **Gemini Image** (Google) — высокое качество, ротация ключей
  2. **Pollinations.ai** — бесплатный, без API-ключа
  3. **Stability AI (SD3.5)** — профессиональное качество
  4. **OpenAI DALL-E 3** — запасной вариант
  5. **HuggingFace Inference** (FLUX.1, SDXL) — бесплатные модели
  6. **Replicate** (SDXL/FLUX) — премиум качество
  7. **Local Fallback Generator** — полностью офлайн, рисует уникальный pixel-art через PIL

- **Особенности**:
  - Все изображения в стиле 2D pixel art с мультяшным персонажем
  - Главный герой: маленький чёрный пиксельный котик с зелёными глазами
  - Автоматический upscale до 1080x1920 (9:16 вертикальный формат)
  - AI-улучшение: sharpening, denoising, enhancement
  - Каждая сцена уникальна по локации, цветовой палитре, освещению

### **AI #3 — Анимация изображений (Image-to-Video)**
*Оживляет статичные картинки, добавляя кинематографичное движение*

- **Доступные провайдеры** (цепочка с fallback):
  1. **fal.ai** (Kling AI) — быстрая генерация видео из фото
  2. **Runway Gen-3 Alpha** — профессиональное качество
  3. **Pika Labs** — стильные эффекты
  4. **Replicate** (Stable Video Diffusion) — локальная генерация при наличии GPU
  5. **Local Motion Engine** — всегда доступен, создаёт Ken Burns эффекты через ffmpeg

- **Валидация**:
  - Каждый клип проверяется на реальную длительность и количество кадров
  - Автоматическая конвертация в канонический формат 1080x1920
  - Проверка на чёрные кадры и артефакты

### **TTS (Text-to-Speech)**
*Озвучивает текст синтетическим голосом*

- **Движки**:
  - **Edge TTS** (бесплатно, хорошее качество)
  - **ElevenLabs** (премиум голоса, требуется API-ключ)

### **Видео-движок (сборка финального ролика)**
*Монтирует все элементы в готовое видео*

- **Компоненты**:
  - Наложение озвучки с субтитрами
  - ASS-субтитры с подсветкой ключевых слов
  - CTA-кнопка ("Подпишись!") в конце
  - Фоновая музыка (опционально)
  - Уникализация для обхода модерации платформ

## 🔧 API Ключи

Все ключи настраиваются в файле `.env` (скопируйте из `.env.example`):

**Бесплатные сервисы (не требуют ключей):**
- **Pollinations.ai** — генерация изображений
- **HuggingFace Inference API** — FLUX.1, SDXL
- **Edge TTS** — озвучка текста

**Премиум сервисы (требуется API-ключ):**
- **DeepSeek / OpenRouter** — LLM для текстов
- **Gemini** — изображения + тексты (ротация ключей)
- **fal.ai** — быстрая генерация видео
- **Runway / Pika** — профессиональное видео
- **Replicate** — SDXL, SVD
- **Stability AI** — SD3.5
- **ElevenLabs** — премиум голоса

## 🐛 Troubleshooting

**Картинки получаются размытыми?**
- Pollinations отдаёт 576x1024 → автоматически делается AI upscale до 1080x1920
- Используйте Stability AI или Gemini для лучшего качества

**Видео не генерируется?**
- Remote провайдеры (fal.ai, Runway) могут таймаутить — система автоматически переключается на Local Motion Engine
- Проверяйте баланс API-ключей

**Бот не отвечает в Telegram?**
- Проверьте токен в `.env`
- Посмотрите логи: `python bot/run_bot.py --bot 1` вручную

**Как работает офлайн-режим?**
- Без интернета используются LocalFallbackGenerator (рисует pixel-art через PIL) и LocalMotionEngine (Ken Burns через ffmpeg)
- Качество ниже, но система продолжает работать
