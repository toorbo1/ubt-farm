# 🎛️ АДМИН-ПАНЕЛЬ UBT Farm - Полный контроль через веб

## ✅ Что доступно:

### 1. 🔑 Управление API ключами
- Редактирование .env переменных прямо в браузере
- Автоматическое скрытие чувствительных данных
- Сохранение одним кликом

### 2. ⚙️ Настройки проекта
- Просмотр текущих настроек (разрешение, FPS, модели)
- Информация о конфигурации

### 3. 📋 Логи сервера
- Мониторинг работы в реальном времени
- Автообновление каждые 10 секунд
- История ошибок и событий

### 4. 📁 Управление файлами
- Список всех сгенерированных картинок и видео
- Удаление ненужных файлов
- Просмотр размеров

## 🚀 Доступ к админ-панели:

### Локально на ПК:
```
http://localhost:5002/admin
```

### С телефона (через локальную сеть):
```
http://<IP_ПК>:5002/admin
```

### Через ngrok (HTTPS, отовсюду):
```bash
ngrok http 5002
# Получишь URL типа https://abc123.ngrok.io/admin
```

## 📊 Порты серверов:

| Порт | Назначение | URL |
|------|------------|-----|
| 5001 | Основное веб-приложение | http://localhost:5001 |
| 5002 | Админ-панель | http://localhost:5002/admin |

## 🔧 Файлы админ-панели:

```
web_app/
├── admin.py              # Сервер админ-панели
└── templates/
    └── admin.html        # Веб-интерфейс управления
```

## 🎯 Как пользоваться:

1. Открой `http://localhost:5002/admin`
2. В разделе "API Ключи" можешь менять токены
3. В "Логах" смотри что происходит
4. В "Файлах" удаляй старые видео/картинки
5. Все изменения применяются мгновенно!
