# Инструкция по запуску бота VenturaVPN

## Требования

- Node.js (версия 14 или выше)
- npm (обычно идет с Node.js)

## Установка

1. Установите зависимости:
```bash
npm install
```

2. Создайте файл `.env` в корне проекта и добавьте:
```env
BOT_TOKEN=your_telegram_bot_token_here
WELCOME_STICKER_ID=optional_sticker_id
```

## Запуск

Запустите бота:
```bash
node bot.js
```

Или в режиме разработки с автоматическим перезапуском:
```bash
npm start
```

## Проверка работы

1. Откройте Telegram и найдите вашего бота
2. Отправьте команду `/start`
3. Вы должны увидеть приветственное сообщение для пользователей без подписки

## Тестирование разных сценариев

### Сценарий 1: Пользователь без подписки
Просто запустите бота: `/start`

**Ожидаемый результат:** Сообщение "Привееет! Каролина на связи ✨ ..."

### Сценарий 2: Оформление подписки
1. Нажмите кнопку "💎 Подписка"
2. Выберите тариф (например, "📅 На месяц")
3. Дождитесь подтверждения

**Ожидаемый результат:** Сообщение об успешном оформлении подписки с деталями

### Сценарий 3: Пользователь с активной подпиской
После оформления подписки нажмите `/start` или кнопку "🏠 К Каролине"

**Ожидаемый результат:** Сообщение "Твоя подписка на VenturaVPN уже активна! ..." с деталями подписки

### Сценарий 4: Получение ключа
Нажмите кнопку "🔐 Забрать ключ" при активной подписке

**Ожижаемый результат:** Ключ доступа в формате `VENTURA-{userId}-{timestamp}`

### Сценарий 5: Продление подписки
При активной подписке нажмите "⚡ Продлить доступ"

**Ожидаемый результат:** Подписка продлена на 1 месяц от текущей даты окончания

## Отладка

Если бот не запускается:

1. Проверьте, что токен бота указан правильно в `.env`
2. Убедитесь, что все зависимости установлены: `npm install`
3. Проверьте консоль на наличие ошибок

## Структура проекта

- `bot.js` - основной файл бота
- `.env` - файл с настройками
- `SUBSCRIPTION_LOGIC.md` - документация по логике подписки
- `test_subscription.js` - тесты логики подписки

## Примечания

- Данные пользователей хранятся в памяти и будут потеряны при перезапуске бота
- Для production использования рекомендуется подключить базу данных (MongoDB, PostgreSQL, Redis)
- Логика подписки автоматически определяет статус пользователя и показывает соответствующее сообщение
