🌐 Бесплатный хостинг

Koyeb.com (рекомендуется)

# 1. Создать аккаунт на koyeb.com
# 2. Нажать "Create Service" → "Deploy from Git"
# 3. Добавить переменные окружения из .env
# 4. Deploy!

Render.com

# 1. Регистрация на render.com
# 2. New Web Service
# 3. Build Command: pip install -r requirements.txt
# 4. Start Command: python bot/run_bot.py --bot 1

📱 Termux на телефоне

# Установить Termux из F-Droid
pkg update && pkg upgrade
pkg install python git ffmpeg openssh

# Клонировать проект
git clone <repo-url>
cd ubt

# Настроить venv
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# Запустить бота
python bot/run_bot.py --bot 1
