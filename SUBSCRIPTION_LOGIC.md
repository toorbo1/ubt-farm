# Логика подписки VenturaVPN

## Обзор изменений

Добавлена логика отображения различных приветственных сообщений в зависимости от статуса подписки пользователя.

## Статусы подписки

1. **none** - пользователь никогда не оформлял подписку
2. **active** - у пользователя есть активная подписка
3. **expired** - подписка истекла

## Где применяется

Логика работает в следующих случаях:

1. **Команда /start** - при первом запуске бота
2. **Кнопка "home"** - при возврате в главное меню

## Оформление подписки

При выборе тарифа (1, 6 или 12 месяцев):
- Сохраняется информация о подписке в памяти (userData)
- Рассчитывается дата окончания
- Показывается подтверждение с деталями

## Продление подписки

Кнопка "renew" продлевает текущую подписку на 1 месяц от даты окончания.

## Получение ключа

Кнопка "key" показывает ключ доступа только для пользователей с активной подпиской.

## Тестирование

Для тестирования разных сценариев:

1. **Без подписки**: просто запустите бота `/start`
2. **С подпиской**: нажмите "Подписка" → выберите тариф
3. **С истекшей подпиской**: вручную измените `endDate` в `userData` на прошедшую дату

## Примечания

- В реальном проекте используйте базу данных вместо `userData` в памяти
- Данные сохраняются только до перезапуска бота
- Для production рекомендуется использовать Redis или другую БД
